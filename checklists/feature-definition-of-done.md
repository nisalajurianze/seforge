# Feature Definition of Done

- [ ] Requirement and acceptance criteria are clear and traceable.
- [ ] Applicable skills were identified.
- [ ] Architecture, data, interface, state, security, privacy, and failure impacts were reviewed.
- [ ] Implementation and configuration are complete and reviewed.
- [ ] Positive, negative, boundary, misuse, failure, recovery, and compatibility tests pass as applicable.
- [ ] Accessibility, performance, platform, and domain checks pass as applicable.
- [ ] Telemetry, ownership, support, migration, and rollback needs are handled.
- [ ] Documentation and evidence register are updated.
- [ ] No critical unresolved defect or unaccepted risk remains.
