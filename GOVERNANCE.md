# Governance

## Roles

- **Maintainers** approve releases, security changes, integrity regeneration, and governance updates.
- **Reviewers** evaluate technical quality, evidence, compatibility, and risk.
- **Contributors** propose scoped changes with tests and source attribution.

## Decision principles

Decisions prioritize:

1. user safety and project integrity;
2. evidence and reproducibility;
3. low user burden;
4. compatibility and reversibility;
5. maintainability and clear ownership.

Material decisions should be recorded in an issue, pull request, or decision record. Security-sensitive details may remain private.

## Releases

A release requires passing validation, unit tests, behavioral evals, pack integrity verification, archive extraction tests, updated documentation, and a reviewed changelog.
