# Quality Gates

## Task gate

A task is not complete until:

- acceptance criteria exist and each criterion has linked passing evidence;
- task-specific skills are selected;
- an ExecPlan exists when risk or scope requires it;
- real verification evidence exists;
- no failing evidence is hidden;
- high or critical findings have a disposition;
- the evidence ledger verifies.

## Release gate

A release is not ready until:

- project facts, routing, and command registry exist;
- release scope is represented by completed tasks;
- no work required for the release remains open;
- evidence exists and its chain verifies;
- plan approval is sufficient for the release;
- migration, rollback, operations, documentation, support, and residual risk are proven or explicitly marked not applicable.

A file existing is structural evidence only. Behavioral claims require actual execution or competent review.
