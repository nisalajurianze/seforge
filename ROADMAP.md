# Roadmap

## Near term

- Expand project-profile regression fixtures.
- Add optional containerized execution adapters for untrusted project commands.
- Add richer task evidence reports and machine-readable release attestations.
- Improve provider-specific context budgeting and catalogue discovery.
- Add more end-to-end examples for mobile, cloud, data, embedded, and AI-enabled projects.

## Longer term

- Signed release provenance and verification guidance.
- Policy-as-code adapters for enterprise environments.
- Multi-agent review orchestration with independent evidence roles.
- Formalized compatibility matrix for supported agent hosts.

Roadmap items are proposals, not commitments. Security and correctness fixes take priority.
