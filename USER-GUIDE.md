# User Guide

The user does not need to learn the 80 skills, edit JSON, or run routine commands.

A normal request is enough:

> Inspect this project, make it professional, use the safest practical option for low-risk decisions, and ask me only before major decisions.

The AI should then:

1. inspect the repository;
2. show what it found;
3. create a project strategy;
4. ask at most three material questions;
5. work in small tasks;
6. run reviewed project checks;
7. record evidence;
8. report progress using Done / Current / Need from you / Risks / Next.

The user is normally interrupted only for:

- unclear desired outcome;
- personal, financial, health, credential, location, or other sensitive data;
- major architecture or supplier commitment;
- destructive migration or data deletion;
- production deployment;
- legal, safety, financial, privacy, or irreversible risk;
- acceptance of known residual risk.

Saying “use the best safe option” authorizes only low-risk, local, reversible work unless a broader approval is explicitly recorded.
